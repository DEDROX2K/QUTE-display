# Contributing to QUTE Display

Thanks for improving QUTE Display.

1. Create a focused branch from `main`.
2. Keep changes limited to the feature or fix being proposed.
3. Test the interface in a modern browser and confirm the main checklist, notes, music, and billboard flows still work.
4. Open a pull request that explains the change and includes screenshots for visual updates.

Do not add personal information, unlicensed media, generated logs, or large binary files unless they are required for the feature and you have permission to share them.
